# DryDock

![Maven Central](https://img.shields.io/maven-central/v/io.github.sinri/DryDock)
![GitHub](https://img.shields.io/github/license/sinri/DryDockOfKeel)

快速构建一个可以运行的Java项目。
目标是打包成jar文件通过命令行运行。

```xml

<dependency>
  <groupId>io.github.sinri</groupId>
  <artifactId>DryDock</artifactId>
</dependency>
```
